# BruzMicroduck CAD

CAD files for a Microduck robot replica built around off-the-shelf sensors,
boards, and other components.

- [`official_design/`](official_design/): original Microduck CAD files used as
  a reference.
- [`replica_design/`](replica_design/): adapted mechanical designs for the
  BruzMicroduck replica.

Designs are provided in STEP (`.step`) format. Open them in a compatible CAD
application to inspect or modify the parts.
